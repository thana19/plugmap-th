# ADR 0003 — หมุดแผนที่แสดงโลโก้ยี่ห้อ

- Status: Accepted (2026-10-26 10:05)
- เกี่ยวข้อง: ADR 0002 (แหล่งข้อมูล My Maps · Provider 14 ค่า) · `docs/prd/ev-charger-map.md` หัวข้อ "Markers & logos"

## Context

MVP เดิมใช้หมุดสีล้วน (ส้ม/น้ำเงิน/เทา ตาม Speed class) บอกได้แค่ความเร็วชาร์จ ต้องกดหมุดจึงรู้ยี่ห้อ
พี่หนุ่มตัดสินใจ (2026-10-26): หมุดต้องแสดง **โลโก้จริงของยี่ห้อ** — "โลโก้จริงในหมุดกลม + ขอบสีความเร็ว"
เพื่อให้เห็นทั้งยี่ห้อและความเร็วในสายตาเดียว

## Decision

1. **รูปแบบหมุด** = Leaflet `L.divIcon` วงกลมประมาณ 36px พื้นขาว โลโก้อยู่กึ่งกลาง
   - **ขอบหนา 3px สีตาม Speed class**: ส้ม = DC เร็ว · น้ำเงิน = AC · เทา = ไม่ทราบ
   - มีหางเล็ก ๆ ชี้ตำแหน่งจริงของจุด
   - หมุดที่ถูกเลือก (selected) ขยายขนาดขึ้น
2. **Fallback:** ไม่มีไฟล์โลโก้ หรือโหลดรูปไม่สำเร็จ (`onerror`) → แสดงตัวย่อ 2–4 ตัวอักษร บนพื้นสีแบรนด์
3. **Cluster:** คง Leaflet.markercluster แบบตัวเลขไว้ตามเดิม · โลโก้แสดงเมื่อซูมเข้าถึงระดับที่แตกกลุ่มแล้ว (เหตุผลด้านประสิทธิภาพ เพราะมีราว 3,000 จุด)
4. **ไฟล์โลโก้** ราว 14 ยี่ห้อ ตาม Provider ใน KML: PTT EV Station PluZ, PEA Volta, EA Anywhere, Sharge, EleXA (EGAT), MG, Altervim, Tesla, Galvanic, EVolt, GWM, MEA EV, OneCharge, Haup
   - ใช้ **ไอคอนแอปทางการของแต่ละยี่ห้อจาก App Store (ตรวจชื่อผู้พัฒนาตรงกับเจ้าของแบรนด์ผ่าน iTunes lookup API · อัปเดต 2026-10-26 10:20: เว็บแบรนด์หลายแห่งดึงอัตโนมัติไม่ได้)** · ที่มาของแต่ละไฟล์อยู่ใน `source_url` ของ `logos.json`
   - แปลงเป็น PNG ขนาด 96×96 เก็บที่ `public/logos/<slug>.png` · ขนาดรวมไม่เกิน 300 KB
5. **Manifest** `public/logos/logos.json` เป็น array ของ `{ slug, operator, color, abbr, file, source_url, fetched_at }`
   - `file` เป็น `null` ได้ → ใช้ตัวย่อ (`abbr`) บนสี `color` แทน
   - `source_url` / `fetched_at` เก็บไว้เป็นหลักฐานที่มาของแต่ละไฟล์
6. **API:** Worker เพิ่มฟิลด์ `operator_slug` ในผลลัพธ์ (ได้จากตาราง alias ใน `normalize.ts`) · frontend map slug → รายการใน `logos.json`
7. **เครื่องหมายการค้า:** โลโก้เป็นเครื่องหมายการค้าของเจ้าของยี่ห้อ ใช้ภายในทีมเท่านั้น
   **ต้องตรวจสอบการใช้เครื่องหมายการค้าก่อนเปิดแอปสาธารณะ** — เป็นเงื่อนไข (gate) เดียวกับเรื่องข้อมูล My Maps ใน ADR 0002

## Consequences

- เห็นยี่ห้อได้ทันทีจากแผนที่ โดยความเร็วชาร์จยังอ่านจากสีขอบ
- ต้องดูแลชุดไฟล์โลโก้และ manifest เพิ่ม · ยี่ห้อใหม่ที่ผู้เขียน My Maps เพิ่มจะยังไม่มีโลโก้ → ใช้ตัวย่อจนกว่าจะเพิ่มไฟล์
- ต้องเพิ่ม slug ใน alias table ทุกครั้งที่เพิ่มยี่ห้อ และมี test กันไม่ให้ Provider ใดขาด entry ใน `logos.json`
- ภาพ 96×96 ต่อหมุดเพิ่ม request/หน่วยความจำ → จำกัดโดย cluster และไฟล์รวม < 300 KB (service worker cache ได้)
- ความเสี่ยงด้านกฎหมายเครื่องหมายการค้า เมื่อเปิดสาธารณะ — ยังไม่ได้ประเมิน

## Alternatives

- **ใช้ตัวย่ออย่างเดียว (ไม่มีโลโก้จริง)** — ปฏิเสธ พี่หนุ่มต้องการโลโก้จริง
- **ให้ผู้ใช้ (พี่หนุ่ม) ส่งไฟล์โลโก้มาเอง** — ปฏิเสธ ใช้ไอคอนแอปทางการแทน
- **หมุดสีล้วนแบบเดิม** — ปฏิเสธ ไม่บอกยี่ห้อบนแผนที่

## Revisit when

- จะเปิดแอปสาธารณะ (ตรวจเครื่องหมายการค้า + ขออนุญาตผู้เขียน My Maps)
- เจ้าของยี่ห้อร้องขอให้ถอดโลโก้
- ประสิทธิภาพแผนที่ตกเมื่อแสดงโลโก้จำนวนมาก
- มียี่ห้อใหม่ใน Provider ของ KML
