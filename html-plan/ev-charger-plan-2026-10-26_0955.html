EV-Charger — แผนที่จุดชาร์จ EV ประเทศไทย

PWA แผนที่รวมจุดชาร์จทุกยี่ห้อสำหรับทีมร้าน EV ใช้บนมือถือ เห็นจุดรอบตัวจาก GPS กดหมุดดู ยี่ห้อ ชนิดหัว จำนวนหัว และ kW แยกความเร็วชาร์จด้วยสีหมุด กดนำทางไป Google Maps ได้ ทีมเพิ่ม แก้ และลบจุดที่เพิ่มเองได้ ข้อมูลตั้งต้นจาก Google My Maps "DC EV Charging Station Thailand" (3,007 จุดชาร์จเร็ว DC) ซิงก์ทุกคืน รันบน Cloudflare (Worker + D1) ตัดการรายงานสถานะ ว่าง/ไม่ว่าง ออกจาก MVP ไปไว้ Phase 2

3. ฟีเจอร์ MVP

  • เปิดแอปแล้วเห็นจุดชาร์จรอบตัวจาก GPS
  • เลื่อนแผนที่แล้วโหลดจุดอัตโนมัติ
  • กดหมุดเห็น ยี่ห้อ ชนิดหัว จำนวน kW
  • แยก DC / AC จากสีหมุด
  • ปุ่มนำทางเปิด Google Maps · ปุ่มแชร์ลิงก์
  • เพิ่มจุดใหม่ (กดค้างบนแผนที่ หรือใช้ตำแหน่งปัจจุบัน)
  • แก้ข้อมูลหัวชาร์จของจุดที่ข้อมูลไม่ครบ
  • ลบจุดที่ทีมเพิ่มเอง (ต้อง PIN, soft delete)
  • กรองตามยี่ห้อ / ชนิดหัว / kW ขั้นต่ำ
  • ติดตั้งลงหน้าจอมือถือ (PWA)
ส้ม · DC เร็ว (≥ 50 kW หรือ CCS2 / CHAdeMO / GB/T DC) น้ำเงิน · AC (Type 2 / Type 1 หรือ < 50 kW) เทา · ไม่ทราบ

5. API และ D1

Endpointหมายเหตุ
GET /api/stations?bbox=max 500 จุด, merge override, ซ่อนจุดที่ถูกลบ
GET /api/stations/:idรายละเอียดจุด
POST /api/stationsต้อง PIN
PATCH /api/stations/:idต้อง PIN, เขียน override
DELETE /api/stations/:idต้อง PIN, เฉพาะ source user (mymaps = 403), soft delete
POST /api/admin/syncต้อง PIN, สั่ง sync เอง
ตาราง D1คอลัมน์หลัก
stationsid (mymaps:<hash> / user:<uuid>), source (mymaps | user), name, name_en, address, hours, operator, lat, lng, connectors_json, raw_json, updated_at, deleted, deleted_by, deleted_at
station_overridesstation_id, name, operator, connectors_json, edited_by, edited_at

KML ไม่มี id คงที่ → id = hash ของพิกัด(ปัดเศษ)+ชื่อ · ถ้าผู้เขียนขยับ/เปลี่ยนชื่อหมุด override เดิมจะกำพร้า (เก็บไว้ ไม่ลบ) · จุดที่หายจาก KML = deleted=1

PIN ส่งใน header X-Team-Pin (secret TEAM_PIN) · rate limit เขียน 30 ครั้ง/ชม./IP

Unit (vitest)

  • parse: ตัวอย่าง Description จริง (2x CCS2: 120 kW, 2x Type2: 22 kW ฯลฯ), fallback kW จาก Power, KML fixture ~5 จุด, id stability
  • normalize: Provider เป็นชื่อมาตรฐาน
  • Speed class: ≥50 kW, CCS2/CHAdeMO/GB/T, AC, ไม่ทราบ, ขอบ 49/50

Integration (D1 local)

  • bbox query
  • POST/PATCH/DELETE ไม่มี PIN = 401
  • DELETE source mymaps = 403, user สำเร็จ
  • จุดที่ถูกลบไม่โผล่ใน bbox
  • override ไม่ถูก sync ทับ
  • จุดที่หายจาก KML = deleted
  • sync ล้มเหลว ข้อมูลเดิมอยู่

E2E / UAT

  • DevTools จอมือถือ: GPS mock, สีหมุด, นำทาง, เพิ่ม/ลบจุด
  • ทดสอบมือถือจริงที่ ev-uat
