EV-Charger — ค้นหาที่หน้าหลัก (จุดชาร์จ + สถานที่)

เพิ่มช่องค้นหาบนแถบด้านบนแทนพื้นที่ชื่อแอป ค้นได้ 2 แบบ: จุดชาร์จ จาก D1 (พิมพ์แล้วขึ้นผลทันที) และ สถานที่ จาก OpenStreetMap Nominatim ผ่าน Worker proxy (ค้นเมื่อกด Enter หรือแตะแถวเท่านั้น ไม่ autocomplete ตาม usage policy)

D1 LIKE tokens ANDNominatim ผ่าน WorkerCache API 24 ชม.ไม่มี DB migration

1. Context

  • พี่หนุ่มเลือกฟีเจอร์ "ค้นหาที่หน้าหลัก" ค้นได้ทั้งจุดชาร์จและสถานที่
  • แอปปัจจุบัน: แถบด้านบนมีชื่อ "จุดชาร์จ EV" + สถานะ ("พบ N จุดในหน้าจอ") + ปุ่ม ★ และ "กรอง" · Worker worker/src/index.ts มี GET /api/stations (bbox / hub) · frontend public/app.js (loadViewport, sheet, withPin)
  • ยังไม่มี geocoder · Google Places ถูกตัดออกแล้ว (ดู ADR 0004)

2. Decisions

จุดชาร์จ: ค้นใน D1

GET /api/stations?q=&lat=&lng= · แยก token ทุกคำต้องตรง (AND) กับ name / name_en / address / operator / ชื่อ override · deleted=0 · สูงสุด 20 · เรียงตามระยะ ชื่อตรงมาก่อน

สถานที่: Nominatim ผ่าน Worker

GET /api/geocode?q= · countrycodes=th, accept-language=th, limit=5, format=jsonv2 · User-Agent plugmap-th/1.0 (+https://ev.thana.in.th) · cache 24 ชม.

ไม่ autocomplete สถานที่

Nominatim policy: ≤ 1 req/วินาที ห้ามยิงขณะพิมพ์ → เรียกเมื่อกด Enter / แตะแถว "ค้นหาสถานที่" เท่านั้น

ปิด dropdown + แผงอื่น

Esc / แตะแผนที่ / เลือกผล = ปิด · โฟกัสช่องค้นหา → แผงกรอง/★ ปิด · เครดิต "ค้นหาสถานที่โดย © OpenStreetMap"

Endpointค่า/กติกาError
GET /api/stations?q=&lat=&lng=q 2–100 ตัวอักษร · สูงสุด 20 · มี distance_km · ไม่ต้อง PIN400 ถ้า q สั้น/ว่าง/ยาวเกิน
GET /api/geocode?q=q 2–100 · คืน {results:[{display_name, lat, lng, type}]} · Cache API 24 ชม. · ไม่ต้อง PIN400 q ผิด · 502 upstream พัง

4. Steps

  1. Docs (เสร็จแล้ว) — PRD, CONTEXT, ADR 0004, HTML plan นี้ → รอพี่หนุ่ม confirm
  2. Implement (senior-programmer) — Worker: ?q= ใน /api/stations (tokens AND, escape LIKE, เรียงระยะ, ชื่อตรงก่อน) + /api/geocode (proxy, UA, Cache API, 400/502)
  3. Frontend — ช่องค้นหาแทนชื่อแอป, ปุ่ม ×, dropdown 2 ส่วน, debounce 300 ms + AbortController, Enter/แถวค้นหาสถานที่, Esc/แตะแผนที่ปิด, ปิดแผงกรอง/★ เมื่อโฟกัส, เครดิต OSM, sw.js bump cache
  4. Tests ใน worker/test — q search + geocode (mock fetch) ต้องผ่านทั้งหมด
  5. รีวิว diff โดยมิกะ → ถามก่อน deploy UAT (ไม่มี schema ใหม่)
  6. UAT ทดสอบ UI บนมือถือ → ถามก่อน PRD → อัปเดต TESTING / handoff / README → push
