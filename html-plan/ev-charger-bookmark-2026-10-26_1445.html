EV-Charger — Bookmark จุดชาร์จ (แชร์ทั้งทีม)

เพิ่มความสามารถ "บันทึกจุดชาร์จ" ให้ทั้งทีมเห็นร่วมกัน เก็บใน D1 ใส่ Team PIN ก่อนเพิ่ม/ลบ แต่ดูรายการได้โดยไม่ต้องใช้ PIN มี 3 ทางใช้งาน: ปุ่ม ★ บนแถบด้านบนเปิดรายการ, ตัวกรอง "เฉพาะที่บันทึกไว้", และดาวทองบนหมุด

D1 ตาราง bookmarksTeam PIN เฉพาะเขียนWorker + PWA

1. Context

  • พี่หนุ่มขอ "เพิ่ม bookmark จุดชาร์จ" · เลือกแล้วว่า แชร์ทั้งทีม (ไม่ใช่เก็บในเครื่องตัวเอง)
  • แอปปัจจุบัน: Worker worker/src/index.ts (route + guardWrite = rate limit + PIN), D1 worker/schema.sql, frontend public/app.js (withPin, filters/passes, hub mode ใน loadViewport, sigOf, bottom sheet)
  • ต้องมีครบ 3 ทาง: ปุ่ม ★ เปิดรายการ · ตัวกรองเฉพาะ bookmark · ดาวบนหมุด

2. Decisions

แชร์ทั้งทีมใน D1

ตาราง bookmarks ไม่มี FK (แบบเดียวกับ station_overrides) · จุดที่ถูกลบ bookmark ยังอยู่แต่ไม่แสดง

PIN เฉพาะเขียน

GET /api/bookmarks เปิดดูได้ · PUT/DELETE ผ่าน guardWrite (PIN + rate limit 30/ชม./IP)

Idempotent

PUT ซ้ำ = สำเร็จเหมือนเดิม · DELETE ซ้ำ = สำเร็จ · PUT จุดที่ไม่มี/ถูกลบ = 404

กรองคู่ Hub ได้

chip "★ เฉพาะที่บันทึกไว้" โหลด /api/bookmarks ไม่สนซูมขั้นต่ำ · passes() เช็คทั้งคู่

CREATE TABLE IF NOT EXISTS bookmarks (
  station_id TEXT PRIMARY KEY,   -- ไม่มี FK
  created_by TEXT,               -- ชื่อจาก ev_name (ไม่บังคับ)
  created_at TEXT NOT NULL
);
EndpointPINหมายเหตุ
GET /api/bookmarksไม่ต้อง{stations, count} เฉพาะ deleted=0 เรียง created_at DESC · มี bookmark: {created_by, created_at}
PUT /api/bookmarks/:stationIdต้องbody {created_by?} · upsert · 404 ถ้าจุดไม่มี/ถูกลบ · คืน StationDto
DELETE /api/bookmarks/:stationIdต้องลบแบบ idempotent
ทุก endpoint ที่คืน station-เพิ่ม bookmarked: boolean ผ่าน LEFT JOIN bookmarks

4. Steps

  1. Docs (เสร็จแล้ว) — PRD, CONTEXT, HTML plan นี้ → รอพี่หนุ่ม confirm
  2. Implement (senior-programmer) — schema, Worker route + bookmarked ใน DTO, frontend (ปุ่ม ★, แผงรายการ, toggle ใน sheet, chip, ดาวบนหมุด), sw.js → ev-shell-v3
  3. Tests ใน worker/test เดิม — ต้องผ่านทั้งหมด (ตอนนี้ 96)
  4. รีวิว diff โดยมิกะ → ถามก่อน deploy UAT
  5. UAT — รัน schema.sql ด้วย --remote บน ev-charger-uat ก่อน deploy → ทดสอบ UI
  6. ถามก่อน PRD (migrate ev-charger-prd ก่อน) → อัปเดต TESTING / handoff / README → push

  • UAT ด้วย Chrome DevTools ที่ 390x844: กด ☆ ใน sheet → ถาม PIN → ดาวขึ้นบนหมุด
  • ปุ่ม ★ เปิดรายการ แตะแถวแล้วบินไปจุด
